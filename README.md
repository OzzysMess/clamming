# Razorbot: A Clam Inspired Digging Robot
This repo contains my work surrounding the developemnt of a digging probe. Inspired by the Pacific Razor Clam, this probe uses vibrations to dig into wet sands.

### Goal: Develop a Probe and Controller for digging into sands
Besides a hardware probe for anchoring into sands, the testing will be used to build an empirical model. From there, a controller for this probe will be optimized for depth and digging speed.

Vibrator compare files: analysis on some tests comparing efficacy of expending more energy vibrating, or adding water flow from the tip.

Master Notes: Contains analysis on efficacy of vibration mass and frequency.
